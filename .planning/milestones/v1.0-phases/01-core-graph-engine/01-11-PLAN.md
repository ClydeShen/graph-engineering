<objective>
Introduce a single structured JSON logger (pino) shared across all components:
Control Plane daemon, HTTP Gateway, and Workers. Replace all ad-hoc console.log/error/warn
calls with structured log calls using canonical LOG_EVENTS event names.

Why pino and not iii Logger:
  - iii Logger (iii-sdk) only works inside registerFunction handlers — it requires
    an active iii engine WebSocket connection and invocation context.
  - Control Plane daemon and HTTP Gateway are independent Node.js processes with no
    iii SDK connection. They would be completely dark with iii Logger alone.
  - pino covers all three components with one dependency. iii-observability can be
    added in production (Phase 2+) via pino-opentelemetry-transport without replacing
    the logger interface.
</objective>

<decisions>
- pino v9.6.0 — lowest overhead (231ms/10k ops vs 556ms for bunyan), native JSON output
- Single logger instance in packages/shared/src/logger.ts — all components import it
- LOG_LEVEL env var controls level (debug | info | warn | error), default: info
- logger.child({ component, scope_id, ... }) adds fixed fields to every log line
- LOG_EVENTS constants (SCOPE_CREATED, EVENT_WRITTEN, etc.) used as message strings
  so log aggregators can group by event type without string matching
- Control Plane: child({ component: 'control-plane', module: 'pulse-fetch|watchdog' })
- Gateway: child({ component: 'gateway', scope_id }) per request
- Workers: child({ component: 'worker', worker: 'graph::...' }) per invocation
</decisions>

<log_schema>
Every log line (pino JSON) includes these fields:
  level     — number (10=trace 20=debug 30=info 40=warn 50=error 60=fatal)
  time      — Unix ms timestamp
  service   — "graph-native-runtime" (base field)
  component — "gateway" | "control-plane" | "worker" (child binding)
  msg       — LOG_EVENTS constant (e.g. "scope.created")
  + any extra fields passed to the call (scope_id, version_hash, etc.)

Example (info, LOG_LEVEL=info):
  {"level":30,"time":1748945000000,"service":"graph-native-runtime",
   "component":"gateway","route":"POST /v1/scopes",
   "scope_id":"...uuid...","plan_hash":"...sha256...","msg":"scope.created"}

Example (debug, LOG_LEVEL=debug):
  {"level":20,"time":1748945000001,"service":"graph-native-runtime",
   "component":"control-plane","module":"pulse-fetch",
   "event_id":42,"event_type":"task_spawned","msg":"pulse.replay"}
</log_schema>
