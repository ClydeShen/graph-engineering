```typescript
app.get('/v1/stream', (c) => {
  return streamSSE(c, async (stream) => {
    const client = await pool.connect();
    await client.query('LISTEN graph_event_ready');
    client.on('notification', (msg) => {
      void stream.writeSSE({ data: msg.payload ?? '' });
    });
    // keep-alive ping every 30s
    while (!stream.closed) {
      await stream.sleep(30000);
      void stream.writeSSE({ event: 'ping', data: '' });
    }
    client.release();
  });
});
```

      ```typescript
      return streamSSE(c, async (stream) => {
        const client = await pool.connect();
        try {
          await client.query('LISTEN graph_event_ready');
          client.on('notification', (msg) => { void stream.writeSSE({ data: msg.payload ?? '' }); });
          while (!stream.closed) {
            await stream.sleep(30000);
            void stream.writeSSE({ event: 'ping', data: '' });
          }
        } finally {
          client.release();
        }
      });
      ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pg_notify payload → SSE client | pg_notify payload is written by occWrite (internal) and forwarded verbatim to SSE; external clients receive it read-only |
| SSE client → Gateway | SSE is one-directional (server push); clients cannot inject data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Information Disclosure | SSE payload forwarding | accept | Payloads originate from internal OCC writes; no external secret in graph_event_ready notifications |
| T-05-02-02 | Denial of Service | unbounded SSE connections | mitigate | Each connection holds one dedicated pg client; pool size bounds max connections; add connection limit header if needed in Phase 7 |
| T-05-02-03 | Denial of Service | pg client leak on crash | mitigate | client.release() called in finally block (or equivalent) before stream exits |
| T-05-02-SC | Tampering | npm installs | mitigate | hono/streaming is already in gateway package.json — no new packages added |
</threat_model>
