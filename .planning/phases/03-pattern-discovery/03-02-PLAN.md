  <behavior>
    - assignClusters(pairs: [string,string][]): given a list of (id_a,id_b) edges, returns a Map<id, clusterId> where every connected component shares one UUID (union-find)
    - assignClusters with disjoint pairs produces distinct cluster IDs per component
    - assignClusters with a chain a-b, b-c yields a,b,c in the SAME cluster
    - discoverClusters(pool): queries un-clustered, non-anti-pattern templates with both embeddings non-NULL; for each, finds neighbors via topology cosine > 0.90 (topology_embedding <=> $1 < 0.10) AND intent distance > 0.50; builds pairs; runs assignClusters; UPDATEs only rows where cross_domain_cluster_id IS NULL
    - Re-running discoverClusters does not overwrite existing cluster assignments (idempotent)
  </behavior>

  <action>
  Create `packages/workers/src/patterns/cross-scope.ts` exporting `assignClusters(pairs)` (pure union-find, no DB) and `discoverClusters(pool)` (DB-backed).

  `assignClusters`: classic union-find / disjoint-set over the set of ids appearing in `pairs`. After unioning, generate one `randomUUID()` per distinct root and map every id to its root's UUID. Pure function — unit-testable without a DB.

  `discoverClusters(pool)`: SELECT id, topology_embedding, intent_embedding FROM procedural_memory WHERE topology_embedding IS NOT NULL AND intent_embedding IS NOT NULL AND is_anti_pattern = FALSE AND cross_domain_cluster_id IS NULL. For each row, run the neighbor query (per-row `ORDER BY topology_embedding <=> $1 LIMIT 50` with WHERE `topology_embedding <=> $1 < 0.10` AND `intent_embedding <=> $3 > 0.50` AND `is_anti_pattern = FALSE` AND `id != $2`) — this per-row ANN form lets PostgreSQL use the HNSW index (Pitfall 1; arbitrary JOIN with `<=>` does not use HNSW). Collect (row.id, neighbor.id) pairs. Run `assignClusters` on all collected pairs. For each (id, clusterId), execute `UPDATE procedural_memory SET cross_domain_cluster_id = $1 WHERE id = $2 AND cross_domain_cluster_id IS NULL` (Pitfall 5 idempotency).

  Use the cosine threshold 0.90 (topology distance < 0.10) and intent distance > 0.50 — both are Claude's-discretion values per CONTEXT.md; cite them in a JSDoc comment as the chosen defaults with the ADR 25 reference.
