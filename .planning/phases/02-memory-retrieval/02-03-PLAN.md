<objective>
Implement SemanticMemoryWorker — triggered by scope_closed events — which distills episodic memory records into semantic memory via LLM, satisfying Gate 3 criterion G3-2. Applies Phase 1 constraint C1 by firing memory_updated event to execution_event_log after every INSERT.

Purpose: Without semantic distillation, the hybrid BM25+HNSW retrieval pipeline has no semantic_memory rows to query and G3-2 cannot pass.

Output: `semantic.worker.ts` (worker + trigger config), `semantic.worker.test.ts` (unit tests), and extension of `packages/workers/src/index.ts` with the new registration block.
</objective>

  ```
  const combined = rows.map((r) => r.content).join('\n');
  // LLM CALL — ADR 22 (distillation from episodic to semantic; cannot be deterministic)
  const fact = await this.llm.chat([
    { role: 'system', content: 'Distill the following execution traces into key facts. Be concise.' },
    { role: 'user', content: writeGuard(combined) },
  ]);
  ```

  Step 3 — INSERT into semantic_memory:
  ```
  await this.pool.query(
    `INSERT INTO semantic_memory (scope_id, content, created_at)
     VALUES ($1, $2, NOW())`,
    [scopeId, writeGuard(fact)],
  );
  ```

  Step 4 — Phase 1 constraint C1:
  ```
  // Phase 1 constraint C1 — every memory write must trace to execution_event_log
  const contentHash = createHash('sha256').update(fact).digest('hex');
  await occWrite(this.pool, {
    scopeId,
    entityId,
    predecessorHash,
    payload: { memory_type: 'semantic', content_hash: contentHash },
    eventType: 'memory_updated',
  });
  ```

  No try/catch in onScopeClosed — errors propagate to iii-sdk caller (matches frontier.worker.ts pattern).
