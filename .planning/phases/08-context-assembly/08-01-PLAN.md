<objective>
Implement D-01/D-02/D-11 (Knapsack importance-stratified weighting) and D-09/D-10 (Wasm tokenizer fallback mode) in the Phase 07 scaffold files.

Purpose: Knapsack Slicing currently only supports 'newest-first' greedy packing. This plan adds a second strategy ('importance-stratified') that prioritizes `conflict_detected`/`scope_closed` events and aggregates repetitive `memory_updated` runs, per ADR-13. It also makes the Wasm tokenizer resilient to load failures via a configurable fallback, removing a hard-crash risk in dev environments (ADR-15 supplement).

Output: `packages/shared/src/tokenizer.ts` (TOKENIZER_MODE fallback), `packages/workers/src/context/knapsack.ts` (importance-stratified strategy), with unit tests for both.
</objective>
