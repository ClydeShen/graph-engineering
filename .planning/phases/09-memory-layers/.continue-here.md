## Critical Anti-Patterns

| # | Pattern | Severity | Prevention |
|---|---------|----------|------------|
| 1 | **Worktree merge from a stale base silently reverts unrelated `.harness/*` and `.planning/STATE.md`/`ROADMAP.md` files** — happened during the 09-03 merge: `.harness/ROADMAP.md` lost 433 lines (TD-A..TD-M tech debt track + Phase 12-16 product arc), `.harness/state.json` and `.harness/phases/07-architecture/.continue-here.json` reverted to ~2026-06-09 content. The executor's own `files_modified` list didn't include these files, but its branch was forked before commits `af68fd2d`/`7af8311d` landed on master, so its merge commit carried the old versions forward. | advisory (caught & fixed this time, commit `3fca5981`) | **After every `git merge <worktree-branch> --no-ff`**, run `git diff <pre-merge-master-sha>..HEAD --stat` and check for ANY file outside the plan's declared `files_modified` — especially `.harness/ROADMAP.md`, `.harness/state.json`, `.harness/phases/**/.continue-here.json`, `.planning/STATE.md`, `.planning/ROADMAP.md`. If any appear with large deletions, `git checkout <pre-merge-master-sha> -- <file>` and `git commit --amend --no-edit` before continuing. Worth considering: rebase worktree branches onto current master immediately before merge to avoid this entirely for Wave 3. |
| 2 | Test fixtures using literal event-type strings like `'graph::scope::opened'`/`'graph::scope::closed'` will fail TS2322 — `CanonicalEventType` only allows `plan_created \| task_spawned \| memory_updated \| conflict_detected \| scope_closed` (`packages/types/src/api.ts`). | advisory | When 09-04 agent writes `reflect.function.test.ts` or touches `episodic.worker.test.ts` deletion, no new fixtures of this kind are expected — but if any mock event fixtures are added, use the 5 canonical values only. |
| 3 | `mock.calls.find()` with a destructured-array type annotation (`([args]: [{...}]) => ...`) causes TS2769 overload mismatch against `mock.calls: any[][]`. | advisory | Use `(call) => { const args = call[0] as {...}; return ... }` instead. |
