scope_closed, reads the full Scope DAG, LLM-extracts intent and outcome summaries, writes an

anti-patterns — all in a single scope_closed pass.

    TRIGGER CONFIG — export const TEMPLATE_PROPOSAL_TRIGGER_CONFIG with type='durable:subscriber',
    function_id='graph::memory::template-proposal', config.topic='graph::scope::closed'.

    CONSTRUCTOR — TemplateProposalWorker takes:
    reader: TrailReader, memory: MemoryRepository, writes: EventWriter,
    llm: LLMProvider, embed: EmbeddingProvider
    All fields private readonly.

    ORPHAN DETECTION HELPER — private detectOrphanEntityIds(events: EventLogNode[]): string[]:
    Build a Set of all predecessor_hash values across all events. For each event, if the event
    has a non-null entity_id AND its version_hash does NOT appear in the predecessorHashes Set,
    that entity_id is a terminal node (orphan). Return deduplicated array via new Set(). This
    captures entity_ids that were written to but never consumed as a predecessor.

    ZERO TOPOLOGY EMBEDDING CONSTANT — private static readonly: '[' + Array(128).fill(0).join(',') + ']'
    Name it ZERO_TOPOLOGY_EMBEDDING. Used as placeholder topology_embedding for orphan anti-pattern
    writes (WL kernel not available in Phase 9; Phase 10 backfills real embeddings).

    onScopeClosed(scopeId: string, entityId: string, predecessorHash: string): Promise<void>:

    Step 1: const events = await this.reader.getScopeEvents(scopeId)
    If events.length === 0, return immediately without any writes or LLM calls.

    Step 2: Build LLM input — serialize events to readable form:
    const scopeText = events.map(e => JSON.stringify(e)).join('\n')
    LLM CALL — ADR 22 (intent/outcome extraction; cannot be deterministic)
    Send system prompt: "You are analyzing an agent execution trace. Extract the primary intent
    and outcome. Return ONLY valid JSON in this format: {\"intent_summary\":\"...\",\"outcome_summary\":\"...\"}.
    Be concise — each field should be one sentence."
    User message: writeGuard(scopeText)
    Parse response with JSON.parse inside try/catch. On parse failure fallback:
    intentSummary = llmResponse.substring(0, 300), outcomeSummary = 'outcome extraction failed'.

    Step 3: LLM CALL — ADR 22 (embedding calls not counted against Worker token budget)
    try { const { vector } = await this.embed.embed(writeGuard(intentSummary) + '\n' + writeGuard(outcomeSummary))
    const embeddingLiteral = '[' + vector.join(',') + ']'
    await this.memory.appendEpisodicSummary(scopeId, entityId, writeGuard(intentSummary), writeGuard(outcomeSummary), embeddingLiteral)
    } catch (embedErr) {
      // Embedding failure — write empty-vector episodic row rather than skip entirely.
      // HNSW index requires non-null embedding: use zero vector as fallback.
      const fallbackEmbeddingLiteral = '[' + Array(1536).fill(0).join(',') + ']'
      await this.memory.appendEpisodicSummary(scopeId, entityId, writeGuard(intentSummary), writeGuard(outcomeSummary), fallbackEmbeddingLiteral)
    }

    Step 4: Write memory_updated event for episodic write (Phase 1 constraint C1):
    await this.writes.write({ scopeId, entityId, predecessorHash,
      payload: { memory_type: 'episodic', content_hash: contentFingerprint(intentSummary) },
      eventType: 'memory_updated' })

    Step 5: Orphan detection and anti-pattern writes (D-05):
    const orphanEntityIds = this.detectOrphanEntityIds(events)
    For each orphanEntityId of orphanEntityIds:
      try {
        await this.memory.insertProceduralTemplate({
          scopeId,
          content: writeGuard('orphan-entity:' + orphanEntityId),
          intentDescription: writeGuard('Orphan node — entity ' + orphanEntityId + ' had no successor events in scope ' + scopeId),
          templateGraph: { orphan_entity_id: orphanEntityId, scope_id: scopeId },
          embeddingLiteral: TemplateProposalWorker.ZERO_TOPOLOGY_EMBEDDING,
          intentEmbeddingLiteral: null,
          isAntiPattern: true,
        })
        await this.writes.write({ scopeId, entityId: orphanEntityId, predecessorHash,
          payload: { memory_type: 'procedural', content_hash: contentFingerprint('orphan:' + orphanEntityId), is_anti_pattern: true },
          eventType: 'memory_updated' })
      } catch { /* orphan write failure must not break episodic write */ }
  </action>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-09-02-02 | Tampering | Orphan detection logic | accept | Orphan detection is pure TypeScript set intersection over version_hash — no external input; false positives result in harmless anti-pattern writes |
| T-09-02-03 | Denial of Service | Scope with thousands of events | accept | getScopeEvents has no row limit (D-02 requires full DAG); Phase 10 can add caps if needed |
