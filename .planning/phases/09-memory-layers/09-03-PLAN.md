<objective>
Update SemanticMemoryWorker to implement the D-06/D-07/D-08 supersession design: the worker
pre-computes an embedding for the LLM-distilled fact, passes it to the updated
insertSemanticFact() which returns a suggestedMerge hint, and explicitly calls supersede()
when the hint is non-null. No auto-supersede; the caller decides (D-08).

Purpose: Semantic memory rows now carry embeddings for HNSW retrieval, and the supersession
chain is maintained when new facts are similar to existing ones.
Output: Updated semantic.worker.ts + updated tests.
